Claude が使えないあいだのカンバンです。データの置き場所を選んでください。

  1. GitHub：非公開リポジトリの local-board/cards.json を読み書きします。初回だけ鍵（トークン）を貼ります。鍵はこの端末の中にだけ保存されます。
  2. PC のフォルダ：GitHub Desktop で取ってきたデータのリポジトリのフォルダを選びます（Chrome・Edge の PC だけ）。
  3. cards.json を選ぶ：どのブラウザでも読めます。保存は「ダウンロードで保存」です。

使い方の全文は データのリポジトリの local-board/README.md。

カードを直す

GitHub でつなぐ


開いたページで「Only select repositories」を押して上のリポジトリを選び、いちばん下の Generate token を押す。出てきた github_pat_… をコピーして上に貼る（名前・期限・権限は入力済み）。
鍵はこの端末のブラウザの中にだけ保存し、GitHub 以外には送りません。空のまま「つなぐ」を押すと、前に貼った鍵を使います。

スマホでも開く

スマホのカメラでこの QR を読んで開くと、つなぎ先（持ち主・リポジトリ）が入った状態で始まります。鍵は入っていないので、スマホでも「鍵を作るページを開く」から1つ作って貼ってください。
