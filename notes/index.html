    Notion の代わりのメモです。カンバンと同じ置き場を使います。

    1. この端末でカンバンをつないでいれば、自動で同じ鍵・同じリポジトリを使います（何もしなくてよい）。
    2. GitHub：非公開リポジトリの notes/ を読み書きします。鍵はカンバンと同じものです。
    3. PC のフォルダ：カンバンと同じ、データのリポジトリのフォルダを選びます（Chrome・Edge の PC だけ）。

    ページは Markdown のファイルなので、このアプリが使えなくてもメモ帳や Obsidian で開けます。

    GitHub でつなぐ

    カンバンと同じものを入れます。カンバンでつないだ端末なら、ここは開かなくてよいです。


    開いたページで「Only select repositories」を押して上のリポジトリを選び、いちばん下の Generate token を押す。出てきた github_pat_… を上に貼る。
    鍵はこの端末のブラウザの中にだけ保存し（カンバンと共用）、GitHub 以外には送りません。空のまま「つなぐ」を押すと、前に貼った鍵を使います。
